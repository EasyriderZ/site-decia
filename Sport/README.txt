Installation : déposer tous les fichiers et le dossier icons/ ensemble dans un même répertoire HTTPS de decia.fr, par exemple /sport/. Ouvrir https://decia.fr/sport/ sur le téléphone. Android Chrome : menu > Installer l’application ou Ajouter à l’écran d’accueil. iPhone Safari : Partager > Sur l’écran d’accueil. Vérifier que manifest.webmanifest est servi avec un type application/manifest+json ou application/json. Important : les données existantes sont dans le localStorage de l’ancienne URL ; un changement d’URL ou d’origine peut les rendre inaccessibles dans la nouvelle page. Exporter les données de l’ancienne page avant migration.
